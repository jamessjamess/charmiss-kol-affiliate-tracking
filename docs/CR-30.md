# CR-30 — Gencode · Other fee · Next expected · New KOL

ใช้กติกาถาวรใน CLAUDE.md · ช่องบังคับต่อ stage อยู่ที่ `rules.stageRequirements()` ที่เดียว · ข้อมูลที่อยู่ / เลขบัญชี / เบอร์โทร เก็บใน **Payee vault (เข้ารหัส CR-16) เท่านั้น**

## 1. เป้าหมาย
- เก็บโค้ด Gencode ที่ KOL ส่งมาไว้กับ deal / โพสต์ หาเจอ คัดลอกได้ รู้ว่าหมดอายุเมื่อไร
- ค่าใช้จ่ายที่ไม่เข้าช่องไหนมีที่ลง
- วันคาดของ Script / Draft ถัดไปไม่บังคับ (มีแค่ Draft 1 ที่บังคับ)
- สร้าง KOL ใหม่ได้ครบในฟอร์มเดียว ไม่สับสน

## 2. เดิม → ใหม่
- Gencode มีแค่ค่าใช้จ่าย / จำนวนวัน · ไม่มีที่เก็บตัวโค้ด → + **Gencodes** (หลายโค้ดต่อ deal · ผูกกับโพสต์ได้)
- Costs ไม่มีช่องอื่นๆ → + **Other fee** (+ รายละเอียด)
- Move → Brief: Expected Draft 1 \* และ Expected script \* (ภาพ) → **Expected script date (optional) ก่อน · Expected Draft 1 date \* หลัง**
- CR-23 §3.2: Draft k → Expected Draft k+1 **บังคับ** → **optional** (ใช้กับ Draft 1 → Draft 2 และ Draft 2 → Draft 3)
- New KOL: Partner type 3 ปุ่ม · Contact / Contact ID แยกช่อง · "Handle" · ไม่มีที่อยู่ / บัญชี · Platform / Profile link ไม่บังคับ → ตาม §3.5

## 3. Spec

### 3.1 Gencodes (Deal modal › Shipments & posts)
- การ์ด **Gencodes** ต่อจาก Posts · ปุ่ม `+ Add codes` → ช่องวางข้อความหลายบรรทัด (วางทั้งก้อนที่ KOL ส่งมาได้)
  - แยกโค้ดอัตโนมัติ: 1 บรรทัดที่ไม่ว่าง = 1 โค้ด · ตัดช่องว่างหัวท้าย · ซ้ำในก้อนเดียวกันหรือซ้ำกับที่มีอยู่ = ข้าม + แจ้ง "1 duplicate skipped"
  - ตรวจชนิดจากรูปแบบ:
    | รูปแบบ | ชนิด |
    |---|---|
    | ขึ้นต้น `#` ลงท้าย `=` (base64) | **TikTok Spark code** |
    | ขึ้นต้น `fbadcode-` | **Meta ad code** |
    | อื่นๆ | **Other** (เตือนเทา "Unrecognised code format" · ยังบันทึกได้) |
  - preview ก่อนบันทึก: ตาราง Code (ย่อ) · Type · Post (dropdown โพสต์ของ deal · default = โพสต์ที่แพลตฟอร์มตรงกันและยังไม่มีโค้ด หรือ "Not linked") · `Save n codes`
- **รายการ:** Code (แสดงย่อ `#c88F2o…Kg=` · ปุ่ม 📋 Copy คัดลอกตัวเต็ม · toast "Copied") · Type · Post · Received (วันที่บันทึก) · **Valid until** (= Gencode start + Gencode days ถ้ามี · ไม่มี = "—") · Status: Active / Expiring (≤ 3 วัน) / Expired · ⋯ Edit · Delete (ยืนยัน)
- ปุ่ม `Copy all` (คัดลอกทุกโค้ดที่ Active คั่นบรรทัด)
- ไม่แสดงโค้ดเต็มที่อื่น: ตาราง Deals / Dashboard / Export ทั่วไป = จำนวนโค้ดเท่านั้น · Backup เก็บครบ · Export แยก "Gencodes" (Manager / Admin เท่านั้น · ⋯ ในหน้า Deals) สำหรับทีมยิงแอด
- log: `gencode_added` · `gencode_copied` · `gencode_deleted` (ไม่บันทึกตัวโค้ดใน log · เก็บแค่ 6 ตัวแรก)
- **ข้อมูลขาด:** deal ที่ Gencode fee > 0 และ Posted แล้ว แต่ไม่มีโค้ด → แถบ Missing "Gencode" (CR-22) · Operations work queue งาน "Collect gencode" รอ KOL (due = post date + 3 วัน)
- Move to Post (CR-23 §3.3): ถ้า Gencode fee > 0 แสดงช่อง "Gencodes (optional)" วางได้ทันที
- Gencode start ว่าง + มีโค้ดแรก → เสนอ `Use first post date` (ปุ่มเดิม)

### 3.2 Other fee (Costs)
- ช่อง **Other fee (฿)** ต่อจาก Expediting fee + **Other fee note** (บังคับเมื่อ > 0 · "What is this for?")
- รวมใน **Total cost** · Committed · Budget vs Actual · Move stage (Confirm QT) ส่วน Costs มีช่องนี้ด้วย (optional)
- Export / Payments แสดงเป็นบรรทัด "Other: <note>"
