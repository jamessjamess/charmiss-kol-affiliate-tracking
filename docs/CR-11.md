## 4. Implementation details

### 4.1 หลักการ
| สิ่งที่ทำ | ภาชนะ | เหตุผล |
|---|---|---|
| **สร้างใหม่** (New / Add / Create / Import / Plan) | **Modal กลางจอ** (`ui.createModal`) | โฟกัสงานเดียว · พื้นที่กว้าง · หน้าหลังถูกพักไว้ชัดเจน |
| **ดู / แก้ของที่มีอยู่** (คลิกแถว / การ์ด) | Drawer ขวา 60% (CR-10 §4.13) | ยังเห็นรายการด้านหลังและสลับรายการได้เร็ว |
| ยืนยัน / ถามสั้น (Discard changes?, Delete?) | Confirm dialog ขนาด S | — |

- เพิ่มของ**ลูก**ขณะ drawer เปิดอยู่ (เช่น `+ Add account` ใน KOL drawer, `+ Add shipment` ใน Deal drawer) → modal ซ้อนเหนือ drawer ได้ 1 ชั้น · ปิด modal แล้วกลับ drawer เดิม
- modal ซ้อน modal **ไม่ทำ** — flow ที่ต้องสร้างของอื่นระหว่างทาง (Create KOL ใน New deal) ใช้ **panel แทนที่ในตัว modal เดิม** + ลิงก์ "← Back to …"

### 4.2 `ui.createModal({ size, title, tabs, body, primaryLabel, onSubmit })`

| ส่วน | Spec |
|---|---|
| ขนาด | **L** = 90vw สูงสุด 1400px · สูง 85vh · **M** = 720px · สูงตามเนื้อหาสูงสุด 85vh · **S** = 480px · มือถือ (< 768px) ทุกขนาดเต็มจอ |
| ตำแหน่ง | กลางจอ · backdrop มืด 40% · หน้าหลังคลิกไม่ได้ · ไม่ scroll หน้าหลัง |
| Header (sticky) | มี tabs → **tabs เป็นหัว** (ชื่อ tab = ชื่อเรื่อง ตามรูปตัวอย่าง Bulk shortlist) · ไม่มี tabs → title (เช่น "New KOL") · ปุ่ม ✕ มุมขวา · บรรทัดรองเทา (บริบท เช่น Campaign ที่กำลังเพิ่มเข้า) |
| Body | scroll ในตัว · padding 24px · ฟอร์มขนาด L ใช้ grid 2 คอลัมน์ได้ |
| Footer (sticky) | ซ้าย: กล่องตรวจ (✕ ! i) **แสดงหลังกด Create หรือหลังออกจากช่อง (touched)** · ขวา: `Cancel` + ปุ่มรอง (เช่น `Create & next`) + ปุ่มหลัก |
| ปุ่มหลัก | ใช้คำว่า **Create** สำหรับการสร้าง (`Create deal` · `Create KOL` · `Create campaign` · `Add n to shortlist` · `Create run`) · ฟอร์มแก้ไขใน drawer ยังใช้ `Save` |
| Dirty check | มีการกรอกแล้วกด ✕ / Esc / Cancel / คลิก backdrop → ถาม "Discard changes?" (Discard / Keep editing) · ยังไม่กรอก = ปิดทันที · คลิก backdrop ไม่ปิดเมื่อ dirty |
| Keyboard | focus ช่องแรกอัตโนมัติ · focus trap ใน modal · Esc = ปิด (ผ่าน dirty check) · Ctrl/⌘ + Enter = ปุ่มหลัก · คืน focus ไปที่ปุ่มที่เปิด modal เมื่อปิด |
| หลังสร้างเสร็จ | ปิด modal · toast "<Thing> created · Open" (อยู่ในกรอบจอ) · รายการด้านหลัง highlight แถวใหม่ 5 วินาที · `Open` = เปิด drawer ของสิ่งที่สร้าง |
| Accessibility | `role="dialog"` · `aria-modal="true"` · `aria-labelledby` = title / tab ที่ active |
