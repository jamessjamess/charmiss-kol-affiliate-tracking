# CR-25 — Partner type (KOL / Affiliate) · New deal ตัวกรองพับได้

ใช้กติกาถาวรใน CLAUDE.md

## 1. เป้าหมาย
- ใช้ระบบเดียวกันดูแลทั้ง KOL และ Affiliate · ข้อมูลและขั้นตอนเหมือนเดิมทุกอย่าง แค่แยกประเภทได้
- หน้า New deal เห็นรายชื่อชัดขึ้น ตัวกรองไม่กินพื้นที่

## 2. เดิม → ใหม่
- KOL Master ไม่มีการแยก KOL / Affiliate → + ฟิลด์ **Partner type** (ใช้ชื่อนี้เพราะ "Type" ใช้กับ kol_type อยู่แล้ว)
- New deal ตัวกรอง 12 ช่องกางตลอด (ตารางเหลือ ~4 แถว) → **แถวด่วน 1 แถว + ปุ่ม `Filters (n)` กาง / พับ**

## 3. Spec

### 3.1 Partner type
- ค่า: **KOL** (default) · **Affiliate** · **Both** · ข้อมูลเดิม = KOL (`partner_type` ว่าง = KOL · ไม่ต้อง migrate)
- รายการค่าอยู่ใน `lookups.partner_types` (แก้ label ได้ที่ Settings › Lists · key คงที่)
- **กรอก / แก้:** New KOL (หน้า KOL Master + tab New KOL ใน New deal) ช่อง **Partner type \*** (segmented 3 ปุ่ม · default KOL) · KOL modal › Overview แก้ได้ · Bulk edit ใน KOL Master (เลือกหลายคน › Set partner type)
- **แสดง:**
  - KOL Master: คอลัมน์ **Partner** ต่อจาก KOL (chip: KOL เทา · Affiliate · Both)
  - New deal ตาราง / การ์ด Pipeline / Deal modal header: chip เล็ก `AFF` หรือ `KOL+AFF` ข้างชื่อ (KOL ไม่แสดง chip เพื่อลดความรก)
- **ตัวกรอง Partner type** (All · KOL · Affiliate · Both = รวมอยู่ทั้งใน KOL และ Affiliate):
  - KOL Master: dropdown ในแถวบน ต่อจาก All tiers
  - New deal: ในแถวด่วน (§3.2)
  - Deals: ใน Filters
  - KOL Master header นับแยก: "911 KOLs · 928 accounts" → "911 partners (KOL 900 · Affiliate 8 · Both 3) · 928 accounts" (ตัวเลขตามข้อมูลจริง)
- **Import (CR-14):** คอลัมน์ optional `partner_type` (KOL / Affiliate / Both · ว่าง = KOL · ค่าอื่น = error แถวนั้น) · ปุ่ม Download template เพิ่มคอลัมน์นี้
- Export KOL Master / Deals: + คอลัมน์ Partner type
- Dashboard ยังไม่แยก (ดู §6 ข้อ 4)

### 3.2 New deal — ตัวกรองพับ / กาง
- **แถวด่วน (แสดงเสมอ):** Search · **Partner type** (segmented All / KOL / Affiliate) · Tier · ☑ Not in this campaign yet · ปุ่ม **`Filters (n)`** (n = จำนวนตัวกรองในส่วนพับที่ใช้อยู่)
- **ส่วนพับ (กดปุ่ม Filters = กาง · กดซ้ำ = พับ):** Platform · Type · Category · KOL owner · Status · Last worked · Performance · Worked in + Posted only · `Clear all filters`
- เมื่อพับและมีตัวกรองทำงาน → แสดง chip ใต้แถวด่วน "Platform: TikTok ✕" · "KOL owner: Amp ✕" (กด ✕ = ล้างตัวนั้น) · มากกว่า 4 ตัว = "+2 more"
- default = **พับ** · จำค่า กาง / พับ ต่อผู้ใช้ (localStorage)
- ตารางใช้พื้นที่ที่เหลือ (พับแล้วเห็นอย่างน้อย 8 แถวที่ 1440×900)
- ตารางคอลัมน์: ปรับความกว้างให้ **KOL owner ไม่ถูกตัด** (ภาพเดิมเหลือ "Am" / "Par") · ลำดับ: ☐ · KOL (+ chip AFF) · Platform · Followers · Tier · Type · KOL owner · Last campaign · Performance
- ใช้รูปแบบเดียวกับปุ่ม Filters ของ KOL Master (หน้าตาเดียวกัน)

## 4. Data
- `kols.partner_type` (`kol | affiliate | both` · null = kol) · `lookups.partner_types` (ใส่ค่า default ตอนโหลดถ้ายังไม่มี) · ไม่มี migration · ไม่แตะเงิน
