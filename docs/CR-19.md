## 4. Implementation details

### 4.1 โครงการ์ด
- ชื่อการ์ด **Campaign timeline** · มุมขวา: `Posts | Spend` (เดิม) · ปุ่ม table / download / expand (เดิม)
- บรรทัดรองใต้ชื่อ: "n campaigns · Today 08/10" + legend: แถบสถานะ (On going · Not started · Pending approval · Complete) · แท่ง Posted (ทึบ) · Planned (จาง + ขอบ)
- Scope = ช่วงวันที่ + Status filter ของ tab (CR-14) เหมือน widget อื่น

### 4.2 1 แถว = 1 Campaign (สูง 40px)
| ส่วน | Spec |
|---|---|
| ซ้าย (คอลัมน์คงที่ 240px · sticky ตอนเลื่อนแนวนอน) | ชื่อ Campaign (ขึ้นบรรทัดได้ ไม่ตัด) · บรรทัดเล็ก: chip สถานะ + "94 posts" หรือ "฿x" ตาม toggle |
| แถบช่วง Campaign | แถบเหลี่ยมสูง 20px จากวันเริ่มถึงวันจบ · **สีอ่อนตามสถานะ** (ชุดเดียวกับ Campaign & Phase › Timeline: On going น้ำเงินอ่อน · Not started เทาอ่อน · Complete เขียวอ่อน · Pending approval เหลืองอ่อนลายทแยง · On hold ลายทแยงเหลือง · Cancelled เทาขีดฆ่า) |
| เส้นแบ่ง Phase | เส้นแนวตั้งบาง 1px ภายในแถบ ที่วันเริ่มของแต่ละ Phase · hover แสดงชื่อ Phase (ไม่ใส่สี Phase ในแถบ — ใช้แค่เส้นแบ่ง) |
| **แท่งกิจกรรม** | แท่งเล็กวางบนแถบช่วง · **1 แท่ง = 1 สัปดาห์** (Mon-first) ตามช่วงวันที่ยาว > 45 วัน · 1 วันเมื่อ ≤ 45 วัน (กติกา timeAxis CR-09) · ความสูงสูงสุด 16px สเกล**เดียวกันทุกแถว** (เทียบกันได้) · สีหมึกเข้มกลาง (ไม่ใช้สีต่อ Campaign) · Posted ทึบ · Planned จาง + ขอบ · ช่อง 2px ระหว่างแท่ง |
| โพสต์นอกช่วง Campaign | แท่งแสดงตามจริงแต่จางลง 50% · นับใน footer "n posts outside the campaign period" |
| ขวาสุด (ไม่บังคับ ≥ 1440px) | Days left / "Starts in n days" ตัวเลขชิดขวา |

- เส้น **Today** แนวตั้งแดงประผ่านทุกแถว (เดิม) · grid เดือนจาง
- แถว Campaign ที่ไม่มีโพสต์ในช่วง: ยังแสดงแถบช่วงตามปกติ (ไม่มีแท่ง) · ตัวอักษรไม่จาง

### 4.3 ลำดับ · ความสูง · การเลื่อน
- **ลำดับแถว:** On going (จบเร็วก่อน → ถ้าเท่ากันเริ่มก่อนก่อน) → Pending approval → Not started (เริ่มเร็วก่อน) → On hold → Complete (จบล่าสุดก่อน) → Cancelled
- การ์ดสูง**คงที่**: แสดงได้ **10 แถว** (≈ 400px plot) · เกินนั้นเลื่อนแนวตั้ง**ในการ์ด** · **แกนเวลาติดบนการ์ด (sticky)** · มีเงาที่ขอบล่างบอกว่ามีต่อ
- ปุ่ม expand (เดิม) → เปิดเต็มจอแสดงทุกแถวไม่ต้องเลื่อน
- ≤ 10 Campaign → ความสูงพอดีจำนวนแถว (ไม่มีช่องว่างเหลือ)

### 4.4 Interaction
- **Hover แท่ง:** สัปดาห์ (dd/mm–dd/mm) · Phase · Posted n / Planned n (หรือ ฿) · hit area ทั้งช่องสัปดาห์สูงเต็มแถว
- **Hover แถบช่วง:** Campaign · Period · Status · Budget · Committed · Used % · Posts n
- **คลิกแถว / ชื่อ:** ไป Dashboard › By campaign ของ Campaign นั้น (คงช่วงวันที่)
- คีย์บอร์ด: Tab ไล่แถว · Enter = คลิก
- Table view (ปุ่ม table): Campaign · Status · Start · End · Posts posted · Posts planned · Spend · First post · Last post

### 4.5 Export
- sheet `Campaign timeline`: Campaign · Status · Start · End · Week (Mon) · Posted · Planned · Spend — 1 แถวต่อ Campaign ต่อสัปดาห์ (หรือวันตาม bucket บนจอ) · ตัวเลขตรงจอ
- ลำดับ sheet ของ tab: Summary · Campaign portfolio · Campaign timeline · Pillar mix · KOL tier mix

### 4.6 Pillar ใหม่ — Awareness & Consideration
- `lookups.pillar_list` ลำดับใหม่: **Awareness → Awareness & Consideration → Consideration → Conversion** (+ Not set)
- label เต็ม "Awareness & Consideration" · label สั้น (chip / แกนกราฟที่แคบ) "Aware + Consider" · แก้ label ได้ที่ Settings › Lists
- สี (ผ่าน validator ชุด 4 สีทั้ง light / dark): Awareness `#2a78d6` / `#3987e5` · **Awareness & Consideration `#008300` / `#008300`** · Consideration `#e87ba4` / `#d55181` · Conversion `#eda100` / `#c98500` · Not set เทา + texture เดิม
  - ไม่ใช้สีม่วง (ชนกับ Mega ใน KOL tier mix ที่อยู่ข้างกัน และแยกจากน้ำเงินไม่ออกในโหมดมืด)
- ใช้ได้ทุกที่ที่เลือก Pillar: Deal (form · inline · bulk Set pillar) · Default pillar ของ Phase · Move to Post dialog · Filters › Pillar · Color by Pillar · Pillar mix · Pillar allocation · Export
- Migration v18: Phase ที่ `default_pillar` ว่าง และชื่อมีทั้งคำ "Awareness" และ "Consideration" → ตั้ง default_pillar = Awareness & Consideration (seed: Perfect Heart Phase 1 "Awareness & Consideration") · **ไม่แตะ deal**

### 4.7 ตัด Pillar target ทั้งระบบ
| จุด | เปลี่ยนเป็น |
|---|---|
| Phase Planner (CR-18) | ตัด checkbox "Use its own pillar target (otherwise the default in Settings)" และช่อง Awareness / Consideration / Conversion (%) |
| Settings › Pillar targets | ตัดเมนู |
| Dashboard › All campaigns › **Pillar mix** (CR-13) | legend เหลือ Pillar · Spend (หรือ Deals) · % of total · ตัดคอลัมน์ Target / Δ · บรรทัดเตือน "x% of spend has no pillar · Set default pillar per phase" คงไว้ |
| Dashboard › By campaign › **Allocation vs target** | เปลี่ยนชื่อเป็น **Pillar allocation** · แสดงแถบสัดส่วนจริงของ Campaign และแต่ละ Phase (4 Pillar + Not set) · ตัดแถบ Target และค่า pp |
| Campaign drawer | ตัดบรรทัด Pillar target |
| Export | ตัดคอลัมน์ Target / Δ |
- ข้อมูล `campaigns.pillar_target` · `lookups.pillar_target_default` **เก็บไว้ไม่ลบ** (ไม่ใช้แล้ว)

### 4.8 KOL budget บังคับกรอก
- Phase Planner: ป้าย **KOL budget (฿) \*** · ต้อง > 0
- ปุ่มหลัก (`Create campaign` / `Submit for approval` · CR-17) กดแล้วถ้าว่าง → ช่องกรอบแดง "Enter the KOL budget" + กล่องตรวจใน footer · ไม่สร้าง / ไม่ส่ง
- ระหว่างกรอก (ยังไม่ touched) ไม่ขึ้นแดง · แถบเตือนส้ม "No campaign budget yet — percentages can't be calculated" ในตาราง Phase เปลี่ยนเป็นข้อความเทา "Enter the KOL budget to use Budget %" จนกว่าจะกรอก
- Campaign เดิมที่ไม่มีงบ: เปิด Plan phases ได้ แต่ Save ต้องกรอกงบก่อน (ข้อความเดียวกัน) · Campaign ที่อนุมัติแล้วเปลี่ยนงบผ่าน Adjust budget (CR-18) เหมือนเดิม
