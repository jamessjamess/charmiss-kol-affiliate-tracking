# CR-29 — KPI cards · Budget vs Actual (ข้อความน้อยลง) · Platform mix · Mark campaign complete · Timeline toolbar

> v1.1 (2026-10-09): + §3.5 Mark campaign complete (Approve) · §3.6 Timeline toolbar · schema 22

ใช้กติกาถาวรใน CLAUDE.md · ตัวเลขทุกตัวใช้ฟังก์ชันเดิม (CR-05 · CR-26) ห้ามเปลี่ยนค่า

## 1. เป้าหมาย
KPI อ่านได้ใน 2 วินาที: ตัวเลขใหญ่ → bar → บรรทัดเดียวพอ · การ์ดทุกใบหน้าตาเดียวกัน · กราฟไม่ต้องอ่านย่อหน้า

## 2. เดิม → ใหม่
- KPI แต่ละใบมีบรรทัดรองไม่เท่ากัน (1–3 บรรทัด) · bar อยู่คนละระดับ · Campaigns / KOL engaged ไม่มี bar → **โครงเดียวกัน 4 แถว** · ทุกใบมี bar · bar อยู่ระดับเดียวกัน
- Budget vs Actual: ข้อความสรุป 2 บรรทัดบน + 2 บรรทัดล่าง → **บรรทัดเดียวบน · บรรทัดเดียวล่าง** (ที่เหลือย้ายไป tooltip / table view)
- แถว mix มี 2 การ์ด (Pillar · KOL tier) → + **Platform mix** (3 การ์ดเท่ากัน)
- Campaign เป็น **Complete อัตโนมัติ** เมื่อเลย End date → **ต้องกด Mark complete** (Staff ต้องได้ Approve) · เลย End date แต่ยังไม่ปิด = **Wrap-up** (§3.5)
- Timeline: Month / Quarter / Fit / Today อยู่แถวตัวกรอง · Sort / Collapse all อยู่กลางแถว → แถว status tabs: tabs ซ้าย · Month… · Sort · Expand/Collapse ชิดขวาสุด (§3.6)

### 3.2 Budget vs Actual — ลดข้อความ
- **บรรทัดสรุปบน (บรรทัดเดียว ต่อจาก legend หรือใต้ชื่อ):** `To date ฿1.20M of ฿2.96M (40%) · Behind ฿1.76M`
  - "Behind" ส้ม / "Over" แดง / ตามแผน (85–105%) = "On plan" เทา
  - ตัด "Rest of year: ฿26,000 committed upcoming vs ฿4,385,412 planned" → ย้ายไป tooltip ของคำว่า "To date" และเป็นแถวสรุปใน table view
- **บรรทัดล่าง (บรรทัดเดียว เทา 12px):** `฿207K not on chart · Set dates` + ⓘ
  - ⓘ อธิบาย: "฿206,800 committed has no post date · ฿4,400 (3 deals) posted or due outside these months"
  - ถ้าไม่มีทั้ง 2 อย่าง → ไม่แสดงบรรทัดนี้
- **ป้ายใต้เดือน:** ย่อเป็นตัวเลขอย่างเดียว `−฿143K` (ส้ม) / `+฿4K` (แดง) · คำว่า Behind / Over อยู่ใน legend ครั้งเดียว ("−฿ behind · +฿ over budget") · tooltip ต่อเดือนเหมือนเดิม
- legend คงไว้ (Posted · Upcoming · Late · Budget) แถวเดียวกับปุ่ม Monthly / Cumulative ถ้าความกว้างพอ

### 3.3 Campaign timeline — ข้อความใต้กราฟ (แนวเดียวกัน)
- `28 posts without a date (not on the chart) · 3 posts dated outside this range (not on the chart) · 45 posts outside the campaign period` → `76 posts not shown` + ⓘ (แยก 3 ประเภทใน tooltip) · ไม่มี = ไม่แสดง

### 3.4 Platform mix (การ์ดใหม่)
- แถว mix เป็น 3 การ์ดเท่ากัน: **Pillar mix · KOL tier mix · Platform mix**
- Platform mix ใช้โครงเดียวกับ KOL tier mix: toggle Spend / Deals · donut + ตาราง (Platform · Deals · Spend · %) · ไอคอนแพลตฟอร์มหน้าชื่อ
- นับจาก committed deal ตามแพลตฟอร์มของ account ที่ใช้ใน deal (TikTok · Instagram · Facebook · X · Lemon8 · YouTube · อื่นๆ) · deal ที่ไม่มี account ระบุ = "Not set"
- สีแพลตฟอร์ม: ใช้ categorical palette ชุดที่ validate แล้ว (ห้ามใช้สีแบรนด์ของแพลตฟอร์ม · ไม่ซ้ำความหมายกับสี Tier ที่อยู่ข้างกัน → ใช้ลำดับสีถัดไปในชุด หรือโทนเดียว (ink ramp) ถ้าชนกัน · ตรวจ light / dark)
- table view · download · expand เหมือนการ์ดอื่น · Export + sheet `Platform mix`
- คำนวณที่ `rules.platformMix(state, filters)`

### 3.5 Mark campaign complete (Campaign & Phase)
**สถานะใหม่**
| สถานะ | เงื่อนไข | สี |
|---|---|---|
| Not started | ก่อน Start date | เทา (เดิม) |
| On going | ระหว่าง Start – End | น้ำเงิน (เดิม) |
| **Wrap-up** (ใหม่) | เลย End date แต่ยังไม่ปิด · งานค้าง (โพสต์ช้า · จ่ายเงิน · metrics) ยังทำต่อได้ | ส้มอ่อน |
| **Complete** | ปิดแล้ว (มี closed_at) เท่านั้น | เขียว (เดิม) |
- precedence ใหม่: Cancelled > Draft > Pending approval > **Complete (closed)** > On hold > **Close requested** (chip ซ้อนบนสถานะวันที่) > Wrap-up / On going / Not started
- status tabs / Status filter ทุกหน้า (Dashboard · Deals · Timeline · Table) + **Wrap-up** · Dashboard ค่า default "All except cancelled" รวม Wrap-up

**ปุ่ม** — ⋯ ของ Campaign (Table · Timeline · drawer) › **Mark as complete** (แสดงเมื่อ On going / Wrap-up · ซ่อนเมื่อ Not started)
- dialog **Close campaign** แสดง checklist งานค้าง (เตือน ไม่บล็อก · คลิกแต่ละข้อไปหน้าที่กรองไว้):
  - Open deals (ยังไม่ Posted / Cancel) n · Payments to pay / sent n (฿x) · Shipments not delivered n · Posts missing metrics n · Committed ฿x of ฿y (Used %)
- ช่อง **Close note** (บังคับเมื่อ checklist มีงานค้าง) · ตัวเลือก ☐ Cancel n open deals that haven't reached Confirm QT (Shortlist / Contacted · reason "Campaign closed")
- **Staff** → `Request close` → คำขอประเภท **Close campaign** เข้า Approvals (ใช้ `requestTransition` · Save draft / Withdraw / Return to draft / Resubmit เหมือน CR-21) · ระหว่างรอ = chip "Close requested"
- **KOL Manager / Admin** → `Close campaign` มีผลทันที (ยืนยันอีกครั้ง) · event `closed`
- Approval review (ประเภท Close campaign): สรุป Period · Budget / Committed / Paid · checklist งานค้าง ณ วันที่ส่ง + ตอนนี้ · Close note · Decision ท้ายสุด (กติกาเดิม)

**หลังปิด (Complete)**
- เพิ่ม deal ใหม่ไม่ได้ (combobox New deal เทา "Campaign is complete") · Adjust budget ไม่ได้
- deal เดิมยังแก้ได้ (จ่ายเงิน · ส่งของ · metrics) · ย้าย stage ได้ · Dashboard นับปกติ
- **Reopen** (Manager / Admin · ⋯ › Reopen campaign · เหตุผลบังคับ) → กลับเป็นสถานะตามวันที่ · event `reopened`

### 3.6 Timeline toolbar (และ Table ใช้แบบเดียวกัน)
- **แถว 1 (ตัวกรอง):** Year · Campaigns · Search · ☐ Include cancelled
- **แถว 2:** status tabs (All · On going · Wrap-up · Not started · Complete) ชิดซ้าย · ชิดขวา เรียงจากซ้ายไปขวา: `Month | Quarter | Fit` · `Today` · `Sort ▾` · `Expand all` / `Collapse all` (ขวาสุด)
- Table: แถว 2 ไม่มีกลุ่ม Month/Quarter/Fit/Today (มีแค่ Sort + Expand / Collapse ชิดขวาสุด)
- คอลัมน์ชื่อ: chip "No products" ย้ายไปบรรทัดใต้ชื่อ (เล็ก) เพื่อไม่ให้ชื่อ Campaign ขึ้น 2–3 บรรทัด (เช่น "Kiss Signal Lip Gloss")
- มือถือ: แถว 2 เลื่อนแนวนอนได้ · ปุ่มไม่ซ้อนกัน
