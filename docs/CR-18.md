## 4. Implementation details

### 4.1 ฟอร์ม Campaign (ซ้ายของ Phase Planner)
ลำดับใหม่: **Campaign name \*** → **KOL budget (฿)** → **Products \*** → **Pillar target** (เดิม)
- ตัด **CTA** และ **Default payment term** ออกจาก Phase Planner (ทั้งโหมด new / edit) — ค่าที่มีอยู่แล้วไม่ถูกลบ · deal ยังเลือก CTA / term ของตัวเองได้ตามเดิม · New deal ไม่ prefill จาก Campaign อีก (มีแค่จาก KOL)
- KOL budget ขึ้นมาอยู่ใต้ชื่อ เพราะตาราง Phase คำนวณจากช่องนี้ · ช่องว่าง (ไม่มีช่องว่างแนวตั้งค้างแบบในรูป)
- โหมด edit ของ Campaign ที่อนุมัติแล้ว: ช่อง KOL budget เป็นตัวเลขอ่านอย่างเดียว + ปุ่ม **`Adjust budget`** (§4.3) · Campaign ใหม่ / ยังไม่อนุมัติ แก้ตัวเลขได้ตรง

### 4.2 ตาราง Phase — กรอก Budget % หรือ Amount ก็ได้
- คอลัมน์: Phase · Label · Period · Days · **Budget %** · **Amount (฿)** · Default pillar · ⋯
- **ตัด toggle `% | ฿`** · ทั้ง 2 ช่องแก้ได้ทุกแถว:
  - พิมพ์ **Amount** → Budget % = Amount ÷ งบ Campaign × 100 (ทศนิยม 2 ตำแหน่ง)
  - พิมพ์ **Budget %** → Amount = งบ Campaign × % ÷ 100 (ปัดเป็นบาท)
  - ช่องที่ผู้ใช้พิมพ์ล่าสุดเป็นค่าหลักของแถวนั้น (`basis: 'amount' | 'percent'`) · เปลี่ยนงบ Campaign ภายหลัง → แถว basis amount คงเงินเดิมแล้วคำนวณ % ใหม่ · แถว basis percent คง % แล้วคำนวณเงินใหม่
  - งบ Campaign ว่าง → Budget % แสดง "—" กรอกไม่ได้ (tooltip "Add the campaign budget first") · Amount กรอกได้ตามปกติ
  - **เก็บข้อมูลเป็นจำนวนเงิน** (`phases.budget_kol`) เสมอ · % เป็นค่าคำนวณ
- ปุ่มลัด: `Even` (แบ่งเงินเท่ากัน เศษไปแถวสุดท้าย) · `Fill remaining` (ส่วนที่ยังไม่จัดสรรไปแถวที่เลือก / แถวสุดท้าย)
- **Budget bar + ข้อความใต้ตาราง** (`rules.phaseBudgetSync`):

| สถานะ | แสดง |
|---|---|
| ผลรวม = งบ | เขียว "Allocated ฿1,000,000 of ฿1,000,000 (100%)" |
| ผลรวม < งบ | **แดง** "Unallocated ฿650,000 · phases total ฿350,000 of ฿1,000,000" |
| ผลรวม > งบ | **แดง** "Over budget by ฿100,000" + แถบส่วนเกินสีแดง |
| ไม่มีงบ Campaign | เหลือง "No campaign budget yet — percentages can't be calculated" (แทนข้อความไทยเดิม) |

- **ก่อน Save:** ผลรวมไม่เท่างบ → แถบสีแดงในกล่องตรวจ footer + กด Save แล้วขึ้น dialog "Phase budgets don't match the campaign budget (Unallocated ฿650,000). Save anyway?" (`Save anyway` / `Keep editing`) — ไม่บล็อก แต่ต้องยืนยัน
- ช่องตัวเลขชิดขวา · แสดงคอมมา · ติดลบไม่ได้ (Error เดิม)

### 4.3 Adjust budget — เพิ่ม / ลดงบหลังอนุมัติ (ต้อง Approve)
**ทางเข้า:** Campaign drawer › Budget › `Adjust budget` · Campaign & Phase › Table แถว Campaign › ⋯ › `Adjust budget` · Phase Planner (edit) ปุ่มข้างช่อง KOL budget

**Dialog `Adjust budget`** (modal M)
| ช่อง | รายละเอียด |
|---|---|
| Current | งบปัจจุบัน ฿x · Committed ฿y (Used z%) · Remaining ฿r · (ถ้ามีคำขอค้างอยู่: "1 request pending +฿100,000") |
| Type | `Increase` (default) · `Decrease` |
| Amount * | ฿ ที่จะเพิ่ม / ลด → แสดง "New budget ฿x" ทันที |
| Allocate to | ตาราง Phase ของ Campaign: Phase · งบปัจจุบัน · **+/− ฿** (กรอก) · งบใหม่ · และแถว **Unallocated** · ปุ่ม `Put all in Unallocated` · `Split by current %` |
| Reason * | เช่น "ยอดขายดี เพิ่ม KOL รอบ 2" |
| Note to approver | ไม่บังคับ |

- ตรวจ: ผลรวม allocations ต้องเท่ากับ Amount (ไม่เท่า = แดง "Allocated ฿80,000 of ฿100,000" · ปุ่ม Submit กดไม่ได้)
- Decrease: งบใหม่ของ Campaign / แต่ละ Phase ต้องไม่ต่ำกว่า Committed (Error "Can't go below committed ฿y")
- ปุ่ม: Staff → **`Submit for approval`** · Admin / KOL Manager → **`Apply`** (อนุมัติทันที ตามกติกา CR-17 · ยังบันทึกในประวัติ)
- คำขอค้างได้ทีละ 1 รายการต่อ Campaign (ยกเลิกเองได้ `Cancel request`)

**ระหว่างรออนุมัติ**
- งบที่ใช้คำนวณทุกที่ = **งบที่อนุมัติแล้ว** (Used % / Remaining ไม่เปลี่ยน)
- แสดงบรรทัดรองที่ช่อง Budget: Campaign & Phase › Table · Campaign drawer · Dashboard › Campaign portfolio · Phase budget → "฿600,000 **+฿100,000 pending**" (เหลือง · tooltip ผู้ขอ / วันที่ / เหตุผล)

**อนุมัติ (ใช้ระบบ CR-17 · tab Approvals)**
- การ์ดชนิดใหม่ **Budget increase / Budget decrease**: Campaign · ผู้ขอ · วันที่ · **Current ฿600,000 → New ฿700,000 (+฿100,000)** · Committed / Used % ก่อน → หลัง (เช่น 57% → 49%) · ตาราง allocations ต่อ Phase · Reason · ปุ่ม `Approve` · `Reject` (เหตุผลบังคับ)
- Approve → `campaigns.budget_kol` และ `phases.budget_kol` อัปเดตตาม allocations · Unallocated เก็บไว้ที่ระดับ Campaign · บันทึก `campaign_events` type `approval`
- Reject → งบเดิม · ผู้ขอเห็นเหตุผลใน My requests และใน Budget history

**Budget history** (Campaign drawer › section Budget)
- ตาราง: วันที่ · Type (Initial / Increase / Decrease) · ฿ · งบหลังรายการ · Phase ที่ได้ · ผู้ขอ · ผู้อนุมัติ · Status · Reason
- **Phase budget** (Dashboard › By campaign) และ Phase Planner: ถ้ามีงบ Unallocated → แถว "Unallocated ฿x" ใต้ Phase สุดท้าย (สีเทา)

**สิทธิ์**
| Action | Admin | KOL Manager | Staff | Viewer | Accounting |
|---|:-:|:-:|:-:|:-:|:-:|
| Adjust budget | ✓ ทันที | ✓ ทันที | ✓ รอ Approve | — | — |
| Approve / Reject คำของบ | ✓ | ✓ | — | — | — |
| ดู Budget history | ✓ | ✓ | ✓ | ✓ | ✓ |
